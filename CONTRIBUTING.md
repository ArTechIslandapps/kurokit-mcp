# Contributing

This repository is a documentation-only mirror generated from the private KuroKit repository. The next sync may overwrite direct changes.

- Typo fixes and documentation suggestions are welcome as issues.
- For setup help, email support@kurokit.com.
- For security problems, follow [SECURITY.md](SECURITY.md).
- Do not include tokens, passwords, personal data, or screenshots with account information.

If you open a pull request, keep it small and explain which page it fixes. A maintainer will copy accepted changes into the private source before the next sync.
